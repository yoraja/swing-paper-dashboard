Chart indicator notes

TradingView Pine Script versions of the setups mirror the backtest rules. The higher-timeframe trend is read from the next timeframe up.

What each indicator draws: - a teal label on a qualifying signal (setup, buy-stop, stop, target 1, reward/risk) - a blue buy-stop line, valid for one bar - red stop, green target 1 and lime target 2 lines - the 5/13 EMAs used for the trailing exit

Alerts fire on the indicator's alert conditions.
